# Screenshot archive

Screenshots used by the public project documentation live in this directory.
Use the `YYYY-MM-DD-page-name.png` naming convention so that replacements remain
traceable without relying on Git history alone.

| File | Surface | Captured | Usage | Privacy check |
| --- | --- | --- | --- | --- |
| `2026-09-03-unlock-screen.png` | Local unlock screen | 2026-09-03 | Root README | No bearer token, API key, email address, or external service URL is visible |

Screenshots are manually selected product captures. Before adding or replacing
one, check for credentials, personal data, local filesystem paths, private Topic
content, and provider account details.
